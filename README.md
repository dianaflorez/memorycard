# Memory Card Game

Este es un proyecto de un juego de memoria desarrollado en React. El objetivo del juego es hacer coincidir pares de cartas en el menor tiempo posible.

## 🚀 Despliegue

El proyecto está desplegado en Render y puedes probarlo en el siguiente enlace:
[Memory Card Game](https://memorycard-pdwg.onrender.com)

## 🛠 Tecnologías Utilizadas

- React
- JavaScript (ES6+)
- CSS
- HTML

## 🔧 Instalación y Uso

1. Clona el repositorio:
   ```sh
   git clone https://github.com/dianaflorez/memorycard.git
   ```
2. Navega al directorio del proyecto:
   ```sh
   cd memorycard
   ```
3. Instala las dependencias:
   ```sh
   npm install
   ```
4. Inicia la aplicación en modo desarrollo:
   ```sh
   npm start
   ```
5. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el juego en acción.
